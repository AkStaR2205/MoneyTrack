# MoneyTrack
1. программа на C++ для учёта доходов и расходов.

2. Цель проекта: создать программу на C++, которая помогает вести учёт личных доходов и расходов.

3. Аудитория: студенты и взрослая аудитория, которым сложно отслеживать куда уходят деньги.

4. Главный функционал:

добавление доходов и расходов
категории расходов
подсчёт баланса
статистика расходов по категориям
поиск конкретных операций

5. Какую проблему решает и как: студенты и взрослые люди (любого возраста) часто не замечают, на что тратят деньги, и к концу месяца их не хватает. Программа хранит все операции в одном месте, считает баланс и показывает, на какие категории уходит больше всего.

6. Чем лучше аналогов: не нужно регистрироваться и устанавливать тяжёлые приложения, интерфейс простой, работает в консоли на любом компьютере, функции только самые нужные.

7. MVP (три главные функции):

Добавление доходов и расходов
Подсчёт баланса
Поиск операций

8. Ограничения проекта (1 этап):

консольный интерфейс, без графики
данные хранятся в массивах, пока открыта программма
ограничение на количество операций (например, 100)

9. Планируемый результат: работающая консольная программа на C++ с меню.

10. Конечный результат: полноценное приложение со своим автономным массивом (сохраняет логи), полностью понятный, простой и красивый интерфейс со всеми нужными функциями, опционально вёрстка на мобильные устройства.
